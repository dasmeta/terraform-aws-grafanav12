# Research
Decision: maintain one local primary subscription through notify-slack and additional cross-region subscriptions through native CloudFormation.
Rationale: AWS::SNS::Subscription.Region targets the source region for create/delete; existing AWS provider 5 can manage the stack and default-region Lambda permissions without optional provider aliases. Stable hash identities and explicit permission dependencies protect lifecycle. Independent Spec Kit research verified official docs and AWS resource-provider source; no runtime mutation was performed.
Sources: https://docs.aws.amazon.com/AWSCloudFormation/latest/TemplateReference/aws-resource-sns-subscription.html ; https://github.com/aws-cloudformation/aws-cloudformation-resource-providers-sns/tree/master/aws-sns-subscription ; https://docs.aws.amazon.com/sns/latest/dg/sns-cross-region-delivery.html ; https://github.com/terraform-aws-modules/terraform-aws-notify-slack/tree/v6.7.0 ; https://github.com/hashicorp/terraform-provider-aws/blob/v5.100.0/website/docs/r/cloudformation_stack.html.markdown .
Alternatives: AWS provider aliases would change the required provider contract; provider 6 per-resource regions require a separate migration; four standalone adapters duplicate functions and environment setups. Neither is needed for the approved common case.
