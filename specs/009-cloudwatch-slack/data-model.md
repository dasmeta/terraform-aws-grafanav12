# Data model
Routing input: enabled flag, stable primary topic ARN, additional topic ARN set, named Slack contact point, function-name override and log-retention days. Existing contact point owns its secret. Adapter: one Lambda, local subscription/invoke permission, log group/IAM and failed-invocation queue. Additional topic: ARN-derived region, unique hashed permission SID and CF logical ID. Stack: only additional SNS subscription resources; template contains no webhook. Outputs expose function ARN and managed topic ARNs, never secrets. Source topics and other subscriptions remain externally owned.
